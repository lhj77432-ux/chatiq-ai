## 三、銷售流程

### 第一步：獲取保單
- Facebook/Instagram 廣告 → 落地頁 → 留電話
-  cold email 私信
- 商會/行業活動

### 第二步：15 分鐘示範
1. 開場 2 分鐘：了解客戶行業、目前怎麼接客
2. 演示 8 分鐘：現場用客戶的真實場景演示
3. 報價 3 分鐘：根據客戶規模推薦版本
4. 收尾 2 分鐘：提供 14 天免費試用

### 第三步：試用期跟進
- 第 1 天：幫忙設定好，確認 WhatsApp 連接成功
- 第 3 天：看數據，了解 AI 回覆質量，微調知識庫
- 第 7 天：展示試用期數據（回覆了多少客戶、多少潛在訂單）
- 第 12 天：提出升級方案
- 第 14 天：正式收費

## 五、技術部署指南

### 本地開發
```bash
cd 一_软件代码/backend
npm install
npm start
# 訪問 http://localhost:3000
```

### 生產環境部署
1. **雲伺服器**：推薦 AWS Lightsail 或 香港數據托管，HK$50-100/月
2. **Node.js**：安裝 v16+
3. **PM2**：進程守護 `npm install -g pm2 && pm2 start server.js`
4. **Nginx**：反向代理 + SSL 證書（Let's Encrypt 免費）
5. **域名**：在 Namecheap 或 網上行動 購買，約 HK$100/年
6. **WhatsApp Business API**：通過 Meta 官方審核，或使用 Twilio/360dialog 中間商

### 環境變量配置
```
PORT=3000
AI_API_KEY=sk-xxxxxxxx
AI_API_URL=https://api.openai.com/v1/chat/completions
AI_MODEL=gpt-4o-mini
WHATSAPP_VERIFY_TOKEN=your_verify_token
```
